Source channels — which one carries your signal?

The three channels of the image as loaded, before any swap. With a full-spectrum sensor behind a filter stack, which channel actually holds the IR or UV response depends on the stack, not on convention — so read it here rather than inferring it from the swapped result. The mean is the channel's average level: a channel sitting near black is mostly noise, and swapping it into a visible slot will amplify that noise.

Each row builds one output channel by mixing the three input channels. If a row's numbers add up to more than 100%, that channel gets brighter; less, and it gets darker — so editing the matrix shifts exposure as a side effect. Normalizing divides each row by its own total, so every row sums to 100% and the mix changes colour without changing brightness. Leave it off if you want a row to deliberately lift or drop a channel.

4. Finishing Controls

Defringe removes the purple/magenta halos IR lenses leave on high-contrast edges. It smooths colour only — edge sharpness is unaffected. Start low; too much desaturates fine detail.
